# Márcio Felipe — Arquitetura & Interiores

Portfólio profissional de Márcio Felipe, com projetos de arquitetura, design de interiores e iluminação.

## Site

O site estático está em `dist/`. A publicação atual é pelo GitHub Pages. A hospedagem independente do Márcio na Locaweb foi ativada e está sendo preparada para receber os arquivos e o apontamento do domínio. Veja `LOCAWEB.md`.

O painel administrativo permite testar localmente com uma senha fictícia ou gravar projetos na coleção `marcioFelipeProjects` do Firestore do projeto Firebase `zoryon-web-portfolio`. A pedido do proprietário, as coleções antigas desse banco foram excluídas em 20/10/2026. A conta administrativa e a configuração pública do app Web estão em `dist/firebase-config.js`; as regras exclusivas do Márcio estão em `firestore.rules` e foram publicadas no console Firebase. As fotos novas são compactadas para WebP e salvas em documentos Firestore, sem Firebase Storage.

## Prévia local

Sirva a pasta `dist` com qualquer servidor HTTP estático.
